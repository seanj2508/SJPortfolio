Analytical Project Experience

Airbnb Pricing Intelligence Dashboard

Built an end-to-end BI pipeline analyzing 7,467 Nashville Airbnb listings, moving from raw data cleaning in Excel through a SQL (SQLite) transformation layer to a 3-page interactive Power BI dashboard. Engineered aggregation views, window functions, and subquery-based sample-reliability flagging to segment districts and host types by price. Found that professional hosts, those managing 6 or more listings, control over half the market and command a roughly 32% price premium while skewing toward High-tier pricing at nearly twice the rate of individual hosts. Also discovered that pricing drops sharply at the 30-night booking threshold, and that premium-tier listings actually convert to bookings less consistently than mid-priced ones, a demand trade-off invisible in the raw averages.

NBA / WNBA Player Props Prediction System

Built an end-to-end sports betting ML pipeline using a PyTorch multi-output neural network trained on 72,000+ game logs across 57 engineered features, pulling live DraftKings lines via The Odds API to calculate expected value on every available prop and filter only statistically favorable wagers. The core challenge was calibration, addressed through head-to-head feature engineering, a rolling nightly bias monitoring system, and a rebuilt prediction function that injects live opponent context dynamically at inference time rather than reusing stale matchup data. Across 400+ live tracked outcomes, high-conviction bets filtered above a 20% edge threshold achieved a 56.7% win rate against a 52.4% breakeven, with a 12-point gap versus unfiltered bets confirming the edge signal is real.

Lung Infection Segmentation from CT Imagery

As part of Wake Forest's AI Club, we took on a faculty-advised research project identifying different types of lung infection in CT scans, where the regions of interest are often just a handful of pixels in a 512×512 image. We built a patch-based feedforward neural network in TensorFlow/Keras, extracting overlapping patches from each scan and training a classifier to label the tissue at their center. The real challenge wasn't the architecture. It was the class imbalance, since healthy tissue vastly outnumbers infected tissue in every scan, so a naive model can hit high accuracy by just guessing the majority class everywhere. We addressed this with aggressive class weighting and reached 76% test accuracy across four tissue classes despite that imbalance. It's still an imperfect model, some predicted regions are far cruder than the ground truth, but it was a real lesson in how deceptive raw accuracy can be on medical imaging data.
